## 首版单设备验收条件（历史）

2026-10-19 用户当时补充：新周期保留所有已明确参榜且未被隔离的身份，0 Token 也参与正常排名，同分并列（全员为 0 时并列第 1；有正数时 0 排在后面），也可生成实际名次分享卡。不再采用最初讨论的“待上榜”方式。0 表示服务端本周期已接收的数量，不保证本机真实用量为零。日界仍为北京时间 00:00，周界仍为周一 00:00，历史不清空。此段已被上方 2026-10-20 多工具总榜规则覆盖。

- 全部本地监测无需试用身份。开始试用时生成 256 位安全随机凭证，仅保存在 Windows DPAPI；服务端只存摘要。创建先持久化，失败可重试，不自动参榜。
- 先预览本周可上传的归一化用量、填公开昵称，再明确确认。第一版只开放经过验证的 Codex 日志来源，其他来源不得用估计值补齐。
- 北京时间日界、周一开始；含缓存输入 + 输出，不重复相加缓存或推理。周榜默认，日榜可切换，同分同名次。
- 一个试用身份只绑定一台设备，不支持跨设备登录、重绑或找回。设备标识随机生成，不采集硬件指纹，也不作为登录密钥。
- 每 30 分钟同步，可手动；断网保留数据重试；事件幂等，重装/复制日志/重试不累计重复用量。读失败不上传假零。
- 暂停不删除既有排名；退出并删除统计、删除试用身份需二次确认。清除本地数据会丢失凭证且停止上传；须提前提醒先删除云端统计。90 天未访问过期，定时清理。
- 仅上传日期、工具、数量、脱敏去重键和设备绑定信息；不上传账号额度、第三方凭据、原始日志、路径、对话或提示词。公开昵称、默认头像、用量与排名，邮箱不公开。
- 服务端验证、速率限制、异常数据隔离；公开说明本地自报数据并非厂商账单或防作弊证明。
- Web 公开榜单和分享卡，无登录表单；桌面提供试用、预览、参榜状态、本人排名和同步时间。
- Windows 安装态必须单独验收；macOS 安全存储未完成时禁用参榜，不宣称可交付。
