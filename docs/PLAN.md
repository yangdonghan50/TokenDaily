# TokenDaily 首版实施计划

依据 `AGENTS.md`、`TokenDaily-Codex-Handoff.md`、`START_HERE.md`。首版定位为 **Windows 上的本地自用 Codex 额度助手原型**：托盘常驻，打开后先看到可信的剩余额度、预计重置时间和数据新鲜度；详情和设置按需展开。技术起点为 Tauri 2 + React/TypeScript + Rust；小规模本地状态使用 JSON。

## 首版范围

必须实现：单个活动 Codex 账户的只读额度接入、实际返回的额度窗口与重置时间、未连接/未知/过期/错误状态、手动与低频后台刷新、托盘和单实例、极简面板/详情/设置、低额度与确认恢复提醒及持久去重、本地数据清除、Windows 安装包。按用户 2026-10-15 新增要求，详情展示来源日 Token 数值、30 天趋势和 13 周日历；日期时区与产品覆盖范围不明时明确标注，不称作本地“今日 Codex 全量”。

明确不做：Ranking/地域/社区及入口、更多提供方、多账号管理、悬浮窗、手机或 IDE 插件、产品注册/云同步/遥测/付费、跨来源合并与复杂预测、费用估算、自动控制 Codex 任务、购买额度或消费重置券。

## 里程碑

| 阶段 | 开发任务 | 验收标准 | 交付物 |
|---|---|---|---|
| M0 数据与环境 | 检查工程和 Windows 工具链；只读探测 Codex App Server；核对账户、池、窗口、时间戳及授权副作用 | 本机真实路径返回有效额度字段；不调用推理或更改 Codex 配置；未测事项单列 | `docs/FEASIBILITY.md`、只读探测脚本 |
| M1 桌面骨架 | 建立托盘、单实例、关闭隐藏；制作主面板、详情、设置与开发专用演示状态 | 浏览器及原生窗口可运行；单窗口、低额度、未知、过期、断连可辨；默认无虚构余额 | Tauri/React 工程、UI 与状态测试 |
| M2 真实数据闭环 | Rust 适配器读取活动身份、额度与日用量；分别规范化、记录新鲜度，低频轮询/退避、脱敏快照 | 真实额度与来源日桶可在安装版显示；任一指标失败不伪装另一项新鲜；重启旧快照标旧；与官方界面同身份同时间核对 | 适配器、缓存与刷新逻辑、契约测试 |
| M3 提醒 | 实现低额度和确认恢复规则、开关/阈值、持久去重、Windows 通知 | 旧数据和倒计时不触发恢复；重启不重复；实际安装态可请求通知，并核对送达 | 规则测试、通知后端、提醒设置 |
| M4 交付验收 | 构建当前用户安装包；测安装、连接、日用量趋势、关闭/退出、单实例、通知、启动项、清除、缩放和资源占用 | 通过项与未测项有明确证据；无凭据/原始对话落盘；不宣称未做的非管理员或缩放验收 | NSIS 包、`README.md`、`docs/TEST_REPORT.md`、更新的 `docs/PROGRESS.md` |

## 仍需验证的技术点

1. Codex App Server 仍被官方标为实验性。当前本机只读路径已实测，正式发行需重新核对授权与稳定性；用户已确定先做本地自用原型。
2. 工作区归属和 Token 日统计的日期时区/产品覆盖范围尚无足够证据。额度按活动账户标识；用量展示来源返回的日期和数量，附口径说明，不称作本机今日或 Codex 全量。
3. 官方 Codex UI 的同时刻数值对照、通知点击、不同 DPI/非管理员环境还需人工验收。安装版手动测试通知已由用户确认可见；这尚不能代替真实低额度/恢复事件的端到端验收。

具体进度和命令结果见 `docs/PROGRESS.md`，分项验收见 `docs/TEST_REPORT.md`。
