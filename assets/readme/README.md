# README 展示素材

采用用户提供的参考版 SVG：白底、深青标题、薄荷绿强调色，顶部引用项目既有渐变 Logo。

| 文件 | 内容 |
| --- | --- |
| `hero.svg` | 悬浮面板、今日用量、额度与积分 |
| `activity.svg` | 13 周热力日历与 30 天趋势；浮窗另有 20 周日历 |
| `community.svg` | 日榜、周榜与个人荣誉示意 |

所有数值、昵称和名次都是合成示例。图片是便于介绍产品的结构示意，不能替代实际截图或平台验收；当前能力见 [功能对照](../../docs/FEATURE_PARITY.md)。费用不是实际账单，额度窗口以来源返回为准；TRAE 未计入云端榜单，榜单中的系统模拟参与者在图文中明确说明。

三张 SVG 自包含，无脚本、外部图片或网络字体；使用系统中文无衬线字体回退，并包含标题与替代说明。来源标识保留 CX / CL / WB / TR 普通字母，品牌与荣誉沿用项目既有图形。

这些展示素材随项目采用 Apache-2.0；该许可不授予项目或第三方的商标权。
