# README 展示素材

- `hero.png`：产品主视觉，深蓝绿色背景、TokenDaily 品牌与真实悬浮面板。
- `workflow.png`：真实用量日历和趋势组件的展示图。
- `panel.png`、`calendar.png`、`trend.png`：0.1.28 公开源码 React 组件的浏览器渲染，全部使用合成数据；没有读取真实凭据、账号或原始日志。预览只说明界面，不构成平台安装态验收。
- `showcase.html`：两张展示图的本地排版源文件，可在浏览器打开；`?view=hero` / `?view=workflow` 切换画布。使用系统字体，无外部资源、网络请求或第三方渲染库。

展示数据固定为 2026-10-22；排名保持未参榜的占位状态，不虚构真实名次。费用为合成的部分覆盖估算，不能视为完整账单。四个来源沿用项目原创 CX / CL / WB / TR 普通标识，不使用厂商品牌图形。

展示素材随项目采用 Apache-2.0；该许可不授予 TokenDaily 或第三方的商标权。
